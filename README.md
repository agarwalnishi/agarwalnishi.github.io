# agarwalnishi.github.io

Source for Nishi Agarwal's personal site. Hand-written HTML and CSS, no framework, no build step. Hosted on GitHub Pages.

| Path | Page |
| --- | --- |
| `index.html` | Home |
| `projects/` | Projects overview |
| `projects/snip/` | Snip case study |
| `projects/specseek/` | SpecSeek case study |
| `about/` | Skills and education |
| `leadership/` | Leadership and achievements |
| `404.html` | Not-found page |
| `style.css` | Shared styles for every page |

Preview locally with `python -m http.server 5500`, then open http://localhost:5500.
